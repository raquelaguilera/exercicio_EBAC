QA Portfolio - Exercícios EBAC

Este repositório contém exercícios de QA utilizando Gherkin (BDD), desenvolvidos durante minha formação na EBAC.


Sobre o projeto

Os cenários foram criados com base em histórias de usuário reais, utilizando:

- Gherkin (Given / When / Then)
- Scenario Outline (Esquema do Cenário)
- Validação de critérios de aceitação
- Testes funcionais manuais

Conteúdo

- Login na plataforma
- Cadastro de cliente
- Configuração de produto

Objetivo

Demonstrar habilidades em:

- Escrita de cenários de teste
- BDD (Behavior Driven Development)
- Análise de requisitos
- Testes manuais estruturados

Tecnologias

- Gherkin
- BDD
- QA Manual Testing
- Git / GitHub
